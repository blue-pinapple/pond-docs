# Code of Conduct

Make sure it is enabled in the `server.properties`  (near top)

```properties
enable-code-of-conduct=true
```

Locate `/default/codeofconduct`

<figure><img src=".gitbook/assets/Screenshot 2025-12-29 at 4.36.35 PM.png" alt=""><figcaption></figcaption></figure>

Then open and edit the text file&#x20;

{% hint style="info" %}
Remeber to save/re-upload
{% endhint %}
