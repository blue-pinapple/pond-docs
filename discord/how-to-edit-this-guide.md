# How to edit this guide

If you're not the owner, go to [https://github.com/blue-pinapple/pond-docs](https://github.com/blue-pinapple/pond-docs).

Each page is indicated by a `.md` file. Locate the one you wish to edit and open it. Press the <i class="fa-pencil">:pencil:</i> to edit. If it says to clone it, clone it. Then do a pull request.
