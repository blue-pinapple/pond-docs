# Code of Conduct

{% hint style="info" %}
The Code of Conduct will only be visible to players on 1.21.9 or above when they first join or when it is updated. Other players will still be able to join but wont see it.
{% endhint %}

Make sure it is enabled in the `server.properties`  (near top)

```properties
enable-code-of-conduct=true
```

Locate `/default/codeofconduct`

<figure><img src="../.gitbook/assets/Screenshot 2025-12-29 at 4.36.35 PM.png" alt="" width="375"><figcaption></figcaption></figure>

Then open and edit the text file&#x20;

{% hint style="info" %}
Remember to save/re-upload
{% endhint %}
